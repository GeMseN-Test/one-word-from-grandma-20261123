## The word

**whatchamacallit**

The single word a grandma would text about AI. When she cannot remember
what the new machine thing is called, she does not say "AI" — she texts
"that whatchamacallit". Warm, a little baffled, funny in one word, and
tied to the machine she cannot name.

## How it works

`main.py` writes exactly that one word — 15 characters, no trailing
newline — to `/output/entry.txt`, deterministically. Every run writes
the same bytes.

```bash
python3 main.py
cat /output/entry.txt   # whatchamacallit
```
